## Goal

Render the per-turn/total token stats the parser already captures, as a status-line footer
(`model · 1,234 in / 567 out (turn) · 8,910 / 4,321 (total)`), shown only when
`!streaming && totalOutputTokens > 0` — tertiary chrome, never inventing data (model-less
payloads render tokens only; totals clause dropped on the first exchange). Take R3-4: land
the SSE `llm.end` parse case so the HTTP transport gets the per-call `↳ X in / Y out`
status lines the stdio transport already renders. Thread `cost_usd` end-to-end (decision
delegated to this issue — taken YES, see Approach §1, including a mandatory JSON-tag bug
fix). Ship the ~30-line client-side display_type heuristic (OD-2): when the wire field is
empty, sniff tool name / hunk markers to pick the existing `diff`/`code`/`bash` renderers;
a non-empty wire field (from #352's server-side `display_type`) always wins.

## Approach

Locked dispositions honored, not re-derived: **R3-5** footer lives in the status line
(chrome), not the header badges (identity/replay slot — #354's territory). **R3-4** land
the `llm.end` parse case now, watch chattiness live at Gate D before folding. **OD-2**
heuristic-first, server field overrides when non-empty; string results only. **B-5**
vocabulary is `code | diff | bash` by convention.

### 1. Cost threading — decision taken: YES, and the wire tag is a bug fix, not a choice

The flagged judgment call from #345 (CostUsd captured on `SSEMessageCompleteData` but not
threaded onto `StreamChunk`) resolves as **thread it now**, because re-verification against
TS `main @ 6cb6f6d` found the current Go declaration is dead on the real wire:

- TS emits **`cost_usd`** (snake_case): `packages/agent-runtime/src/transport/sse-formatter.ts:183`
  — `if (event.costUsd !== undefined) payload.cost_usd = event.costUsd;` (landed with
  #324, live since the harness-runners merges). It also now emits `finish_reason` (L184)
  — no cockpit consumer, ignored (Out of scope).
- Go declares `CostUsd *float64 \`json:"costUsd,omitempty"\`` (`internal/sse/types.go:29`)
  — written speculatively against the harness-runners B1 draft before the TS key existed.
  **It can never decode the actual wire key.** Fix the tag to `json:"cost_usd"`.

Threading is then four small changes: `StreamChunk.CostUsd *float64` (next to the token
fields), populate in `parse.go`'s `ChunkMsgComplete` return, stash `lastCostUsd` in both
model paths, render as a trailing `· $0.0123` clause when non-nil.

**Semantics (from the #324 comment: "harness-reported total run cost"):** `cost_usd` is a
run-total, NOT a turn delta — so it is **never accumulated** (summing run-totals
double-counts). The stash assigns **unconditionally** per `ChunkMsgComplete` (nil clears):
a cost-less turn (plain `AgentRunner` has no cost signal) must not show a stale dollar
figure next to fresh token counts — "never invent" applies to going stale, too.

### 2. Totals accumulation (`internal/chat/model.go`)

Add to the Model struct, next to the existing stash block (L226-229):

```go
totalInputTokens  int
totalOutputTokens int
lastCostUsd       *float64
```

Extend **both** existing `ChunkMsgComplete` cases — `handleResponse` (L1218-1221) and
`skipStreaming` (L1472-1475) — with:

```go
m.totalInputTokens += chunk.InputTokens

```

Known limits (accepted, note in PR): an aborted/cancelled turn emits no `message.complete`

### 3. Footer render (`internal/chat/view.go`)

The status line (`View()` L71-94) is the footer slot. Current chain (#350's work):
`m.pendingInput != nil` → `⏸ awaiting your decision`; `else if m.streaming` → `  ...`.
The footer is the **final else** — structurally collision-free with the HITL status
(`pendingInput` parks with `streaming == true`, so both existing branches shadow it):

```go
} else if fl := m.footerLine(); fl != "" {
    statusContent = fl
}
```

New helper in view.go (extracted for testability):

```go
// footerLine renders the post-turn token/cost footer, or "" when there is
// nothing truthful to show (streaming, pending input, or zero tokens).
func (m *Model) footerLine() string
```

- Guard: `m.streaming || m.pendingInput != nil || m.totalOutputTokens == 0` → `""`.
- Format: clauses joined with ` · `:
  1. `m.lastModel` — omitted when empty (token-only render; never invent);
  2. `fmt.Sprintf("%s in / %s out (turn)", formatNumber(m.lastInputTokens), formatNumber(m.lastOutputTokens))` — always present;
  3. `fmt.Sprintf("%s / %s (total)", formatNumber(m.totalInputTokens), formatNumber(m.totalOutputTokens))` — omitted when totals equal the turn values (covers "drop totals clause on first exchange");
  4. `fmt.Sprintf("$%.4f", *m.lastCostUsd)` — omitted when nil.
- Style: `atoms.TextBlock(inlineCtx, atoms.TextBlockData{Text: ..., Style: theme.Style{Hierarchy: theme.Tertiary}})`
  — dim chrome, matching the dossier's intent; `formatNumber` already exists
  (`model.go:1611-1625`, comma grouping).
- The right-aligned scroll indicator needs **zero changes**: the pad computation (L84-93)
  is generic over `lipgloss.Width(statusContent)`.

### 5. display_type heuristic (`internal/chat/displaytype.go`, new — OD-2, ~30 lines)

The render side already dispatches: `renderToolResult` (`view.go:674-715`) switches on
`tc.DisplayType` with `diff` → `molecules.DiffBlock` + `ParseUnifiedDiff` +
`Arguments["path"]`, `code` → `atoms.CodeBlock` + path-inferred language, `bash` →
`atoms.CodeBlock{Language: "bash"}`, default → plain text. The heuristic is purely a
classifier feeding that existing switch.

```go
// classifyDisplayType guesses a display_type ("bash" | "diff" | "code" | "")
// for a completed tool call whose wire frames carried none. Conservative:
// "" (generic render) beats a wrong rich render.
func classifyDisplayType(toolName string, args map[string]any, result string) string
```

Classification order (rationale: misrendering plain text as a bash block is harmless
monospace; misrendering as a DiffBlock mangles it — so the cheap-safe signal goes first,
the risky one demands strict shape):

1. **bash** — lowercased `toolName` contains one of `bash`, `shell`, `terminal`, `exec`,
   `command` → `"bash"`.
2. **diff** — `result` has strict unified-diff shape: starts with `diff --git` or `--- `,
   or contains a `\n--- ` + `\n+++ ` header pair, AND contains a `\n@@ ` hunk marker
   (`@@ ` prefix counts at string start) → `"diff"`.
3. **code** — lowercased `toolName` contains one of `read`, `write`, `edit`, `cat`,
   `file`, AND `args["path"]` is a non-empty string → `"code"` (consistent with the
   renderer, which only reads `Arguments["path"]`).
4. Otherwise `""`.

**Call site — one choke point for both stream paths:** `fillToolCallResult`
(`model.go:1392-1405`), which both `handleResponse → completeToolCall` and
`skipStreaming → completeToolCallIn` funnel through:

```go
if p.ToolCall.DisplayType == "" {
    p.ToolCall.DisplayType = chunk.DisplayType // adopt end-frame wire field (start-frame drift-fix: today it is ignored)
}
if p.ToolCall.DisplayType == "" && chunk.ToolError == "" && chunk.Result != "" {
    p.ToolCall.DisplayType = classifyDisplayType(p.ToolCall.Name, p.ToolCall.Arguments, chunk.Result)
}
```

- **Wire wins (B-4 seam with #352):** the two-step order makes any non-empty wire field —
  start frame (already stored at `model.go:1130` / `model.go:1433`) or end frame (adopted
  here; today `fillToolCallResult` drops it) — always beat the heuristic. #352's spec
  states the identical contract from the TS side ("server-declared field wins whenever
  non-empty"); no coordination needed beyond the `code | diff | bash` vocabulary.
- **String results only (documented limit, B-5):** object-returning tools already collapse
  to `Result == ""` in `parse.go` (`d.Result.(string)` type-assert), so the
  `chunk.Result != ""` guard enforces the limit structurally. Errors are excluded — the
  error render path pre-empts display_type dispatch anyway (`view.go:681-687`).
- Classify **once at completion**, stored on the part — not per-render (render runs on
  every frame; classification on a large result should not).

## Open questions

1. **Cost threading (the delegated #345 judgment call)** — taken YES here because the tag
   fix is mandatory anyway and the render is one conditional clause. If you'd rather ship
   tokens+model only, §1 splits cleanly: land the tag fix + StreamChunk threading, drop
   the `lastCostUsd` stash + render clause (2 lines each).
2. **Cost precision** — `$%.4f` proposed (typical turn costs are sub-cent). Alternative:
   trim trailing zeros, or `%.2f` above $1. Implementer may pick within "4 significant
   decimals, never scientific notation" unless you object.
3. **Heuristic ordering** — bash-name before diff-markers (§5 rationale: a wrong bash
   block is harmless, a wrong DiffBlock mangles). Means `bash` running `git diff` renders
   as a bash block, not a DiffBlock. Confirm this conservative trade.
4. **`lastCostUsd` nil-clears** on a cost-less `message.complete` (§1) — reads "never
   invent" as "never go stale". Alternative: keep last-known cost with a staleness marker
   — rejected as over-design at this scale.
