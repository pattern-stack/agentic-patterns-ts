# go: charm dependency bump (bubbletea/bubbles/lipgloss v2 patches) + TUI smoke

> **Cross-repo note:** tracker issue lives in `pattern-stack/agentic-patterns-ts`; the code
> change lands in `github.com/pattern-stack/chat-patterns` on branch **`cockpit/deps`**
> (revival base pinned at `187411b`). All `file:line` anchors below refer to chat-patterns
> at that base.

## Goal

Move chat-patterns from `charm.land/bubbletea/v2 v2.0.2` / `bubbles/v2 v2.0.0` /
`lipgloss/v2 v2.0.2` to the plan-locked targets **v2.0.8 / v2.1.1 / v2.0.5** in a
dedicated, zero-code-change PR (OD-4: bump first, dedicated PR), with a **recorded manual
smoke of the key/mouse surfaces** — so every behavioral fix that follows (#344+) diffs
against settled charm behavior and is never entangled with dependency drift.

## Approach

**Base and branch.** Branch `cockpit/deps` off chat-patterns `main` **after #342 (hygiene)
merges** — this PR must be gated by the CI `check` workflow #342 introduces (`just
quality`). If #342 is approved-but-unmerged when work starts, stack on its branch and
rebase onto `main` before merge.

**Targeted bump, not blanket.** Pin exactly the three charm modules; do **not** run a
repo-wide `go get -u ./...`:

- `charm.land/bubbletea/v2` `v2.0.2 → v2.0.8` (latest v2 patch; tag verified 2026-07-22)
- `charm.land/bubbles/v2` `v2.0.0 → v2.1.1` (latest v2; see version-pin note below)
- `charm.land/lipgloss/v2` `v2.0.2 → v2.0.5` (latest v2 patch; tag verified 2026-07-22)

then `go mod tidy`. Indirect modules that Go's MVS raises alongside (ultraviolet,
`charmbracelet/x/ansi`, colorprofile, `x/term`, …) are accepted as part of the charm bump.
The other direct deps — chroma v2, goldmark, yaml.v3 — are untouched. Leave `go 1.25.0` in
`go.mod` (plan §6; bubbles v2.1.1 itself declares `go 1.25.0`, so no toolchain pressure).

**Version-pin note (bubbles).** The issue title says "v2 patches", but the bubbles v2.0.x
line has **no patch releases** — the only forward moves are v2.1.0/v2.1.1. The plan YAML's
`files` field locks `bubbles/v2 v2.0.0→v2.1.1` explicitly, and the v2.1.x delta is
**textarea-only** (v2.1.0: textarea `DynamicHeight`; v2.1.1: textarea prompt-style fix).
chat-patterns imports only `bubbles/v2/key` and `bubbles/v2/viewport`
(`internal/chat/model.go:9-10`) and hand-rolls its input (`internal/chat/input.go:9-10`),
so the bump is behaviorally inert here. Cross-check: bubbles v2.1.1's own go.mod requires
bubbletea ≥v2.0.7 and lipgloss ≥v2.0.4 — both satisfied by our pins.

**What actually changes in the delta** (release-note scan, drives the smoke checklist):

- bubbletea v2.0.3 — extended keyboard-enhancement support; renderer resets terminal tab
  stops. v2.0.4 — `x/ansi` width-calculation fix. v2.0.5 — stray debug-log file removed.
  v2.0.6 — wide-character skip/infinite-loop (CPU spike) fix. **v2.0.7 — cursedRenderer
  mouse data race; mouse-release correctness under the Kitty keyboard protocol;
  input-reader restore skip when input unavailable.** v2.0.8 — emoji grapheme rendering.
  → v2.0.3 and v2.0.7 are exactly the Risk-7 territory (key/mouse event behavior).
- lipgloss v2.0.3 — background-color query hang fix: touches the `HasDarkBackground`
  auto-theme path (`tui.go:41-47`). v2.0.4 — closed-wrap-writer panic fix. v2.0.5 — emoji.
- bubbles v2.1.0/v2.1.1 — textarea only (inert, see above).

**Sequence.** Bump → `go build ./...` + `go test ./...` → manual smoke checklist (Tests
section) with results pasted into the PR description → CI `check` green → merge. **If any
smoke item deviates from base behavior: STOP.** Report the deviation on #343 with a repro;
do **not** fix it inside this PR — behavioral fixes belong to #344+ or a new issue (human
decides ordering). The dedicated-PR discipline is the whole point of OD-4.
