Delta Frames — a state ledger for the playground chat

Today the chat timeline shows what agents said and which tools they called — but the actual product of a multi-stage run (the Backpack accumulating deduped evidence, the Scratchpad slots the framework silently writes) is invisible by construction. Delta Frames makes every state mutation a first-class timeline citizen: a new state_delta part kind rendered as collapsed diff cards in the exact grammar of the existing tool cards — plus a Memory rail — the run’s scratchpad — that answers “what does the agent carry right now.”

The playground, mid-run

The /chat route running the CRM retrieval agent (retrieve → correlate → brief) against: “Where does the Meridian Health deal stand? Pull the latest observations and the artifacts backing them.” The retrieve stage drops observations about the deal into the backpack; hydrateThenDrop then expands them to their associated artifacts (the gong call, the email thread) via the observation → artifact citation refs. Note the tool outputs: a backpack-aware tool drops the full dataset into the pack during execution and returns only a compact receipt to the model — the minted [#N] handles plus one rendered line per entry. The heavy payload never re-enters the context window; the Δ frame beneath the tool card is the lossless record of what actually landed. Everything violet is new. The memory: density toggle and the Memory rail’s seek buttons are functional in this mockup — click around. (Deal content is fictional; shapes match the CRM tools.)

Rail v3 — the self-captioning Memory rail. “Memory · the run’s scratchpad” names what the rail is; each group caption names who wrote it: Evidence ↳ dropped by tools, Stage outputs ↳ saved by the framework, Kept values ↳ written by agent code — three hands writing into one shared memory, so the grouping is the taxonomy, not an arbitrary list. Sans words say what things mean; mono tokens stay letter-for-letter what the runtime calls them (backpack.observations, agents.retrieve) — the mono string is the join key with the timeline. Try the bridge both ways: click a rail row to jump to the Δ frame that wrote it, or click a mono key inside any Δ frame to find its row in the rail. The ledger ships collapsed by default (open here to demo the strike-through cut story); collapse it and hover a citation chip for the peek line.

Ledgerline

“The transcript becomes a git log of state: every drop, expansion, and scratchpad touch is a compact, seekable ledger row inline between the messages that caused it.”

grafted → linkified [#N] handle chips in assistant prose; the 3+-frame coalescing rule; the gate-absence taught line; the single monotonic per-run write ordinal.

Carry — the Live Inventory Rail

“A persistent right-rail inventory showing exactly what the agent carries right now — every drop, expansion, merge, and read rendered as a living, cross-highlighted state view.”

grafted → the entire State rail, built as a pure foldInventory(events[0..cursor]) so replay-scrubbing re-materializes state at any point; carrier dots; honest “unattributed” degradation.

The Provenance Loom

“Every item is a thread: watch evidence get dropped, expanded, merged, carried across agents, and finally woven into the answer.”

grafted → lineage lighting (click a [#N] to highlight every frame that touched it); tagsFor(id) provenance pills on entry hover; the ƒ-gate framing of the expansion pane.

What it takes to power this

Everything shown is a lossless projection of values the runtime already mints (DropReceipt, DropRecord, WriteManifest, [#N] indexes) — the UI fabricates nothing. What’s missing is the eventing.

New events

  • backpack.drop — receipt counts, per-raw rows, size before/after, tag, tool_call_id
  • backpack.read — reader, memo hit|miss, write generation
  • backpack.absorb — branch index, appended handles
  • backpack.travel — UI-derived in v1 from drop events + step boundaries (no new emitter)
  • scratchpad.write / scratchpad.read — slot, op, origin: innate|explicit, byte-capped previews
  • scratchpad.fork / .join — merged + discarded keys
  • step.start/end — already declared & rendered, but has zero production emitters; wiring it is a prerequisite

Emission strategy — invariant kept

  • backpack.ts stays silent — a test structurally proves it never emits; don’t touch it
  • Decorate the Scratchpad: composites install an ObservedScratchpad when an event bus is present (covers set/update/fork/join)
  • Instrument the accessors: requireBackpack/openBackpack return a proxy that forwards drop()/absorb() then publishes
  • Previews byte-capped server-side, honest “(preview only)” notes — never fabricate, never silently clip

UI shipping path

  • New Part kind state_delta — the codebase’s own recipe: a case in applyParts, a component in PartView, a storedPartsToParts case for replay
  • State rail = third tab next to Universe | Trace; pure fold, scrub-aware
  • Density toggle defaults to Writes (reads/innate as one-liners); Off is the escape hatch
  • v1 without new events: travel frames + rail derived client-side from drop events alone
